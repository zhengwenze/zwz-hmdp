## 5. MySQL 验证命令与结果

### 5.1 确认测试券基础数据

```bash
docker compose exec -T mysql mysql -uroot -proot -D hmdp \
  -e "SELECT v.id, v.title, v.type, v.status, sv.stock, sv.begin_time, sv.end_time
      FROM tb_voucher v
      JOIN tb_seckill_voucher sv ON v.id = sv.voucher_id
      WHERE v.id IN (90302041221,90302041222,90302041223,90302041224)
      ORDER BY v.id;"
```

应截图证明：

- `tb_voucher.type=1`
- `tb_voucher.status=1`
- `tb_seckill_voucher.stock`
- `begin_time`、`end_time`

### 5.2 验证正常下单订单生成

```bash
docker compose exec -T mysql mysql -uroot -proot -D hmdp \
  -e "SELECT voucher_id, COUNT(*) AS orders, GROUP_CONCAT(id ORDER BY create_time) AS order_ids
      FROM tb_voucher_order
      WHERE user_id = 1011
        AND voucher_id IN (90302041221,90302041222,90302041223,90302041224)
      GROUP BY voucher_id
      ORDER BY voucher_id;"
```

实际结果：

```text
voucher_id     orders  order_ids
90302041221    1       586634477560659969
```

### 5.3 验证正常券订单数

```bash
docker compose exec -T mysql mysql -uroot -proot -D hmdp \
  -e "SELECT COUNT(*) AS normal_order_count
      FROM tb_voucher_order
      WHERE user_id = 1011 AND voucher_id = 90302041221;"
```

实际结果：

```text
normal_order_count = 1
```

### 5.4 验证失败场景不生成订单

```bash

  -e "SELECT COUNT(*) AS failed_scene_order_count
      FROM tb_voucher_order

```

实际结果：


### 5.5 验证 MySQL 秒杀库存
