# 秒杀优惠券说明

## 为什么同一用户不能重复下单

为了防止用户重复抢购同一张优惠券，系统限制同一用户对同一优惠券只能下单一次。秒杀入口会先通过 Redis Lua 脚本完成库存校验和一人一单校验，通过后再写入 Redis Stream，由后台消费者异步创建订单。

## 秒杀失败的常见原因

1. 优惠券不存在。
2. 秒杀尚未开始。
3. 秒杀已经结束。
4. 库存不足。
5. 当前用户已经下过单。

## 秒杀订单创建链路

秒杀请求通过 Lua 脚本校验资格后，会把订单消息投递到 Redis Stream `stream.orders`。后台消费者组 `g1` 读取消息并创建订单，数据库落库前还会使用 Redisson 锁作为兜底，避免并发场景下重复创建同一用户的同一优惠券订单。
