# HMDP RAG 知识库示例

本目录用于存放 RAG 智能客服的知识文档。

当前 MVP 约定：

- 支持格式：`pdf`、`md`、`txt`、`docx`
- 后端默认扫描目录：`docs/rag`
- 管理页面只负责查看状态和触发重建，不负责上传文件

建议文档写法：

## 标题清晰

优先使用明确的小节标题，例如“如何重建知识库索引”“Ollama 本地模型要求”“Milvus 启动方式”。

## 一段只讲一件事

这样更利于切片和召回，避免一个 chunk 混入多个主题。

## 提供明确步骤

对于运维或排障场景，优先写成分步骤说明，便于客服直接给出可执行回答。

## 更新后重建索引

模型名称、端口、目录路径变更后，需要重新触发“重建索引”。
